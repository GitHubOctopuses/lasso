# lasso · 视频下载器

**lasso**（套索）是一个本地运行的全中文视频下载器：双击启动，浏览器里粘贴链接、
选清晰度、看进度，文件直接进「下载」文件夹。没有广告，没有假下载按钮，
数据不出你的电脑。

基于 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 引擎，支持哔哩哔哩、抖音、快手、
小红书、微博、YouTube、X（推特）、Instagram、TikTok 等 1800+ 网站。

## 快速开始

**双击 `启动 lasso.vbs`** —— 全程无黑色命令行窗口：后台静默启动服务并自动打开浏览器。

- `停止 lasso.bat`：双击停止后台服务
- `启动 lasso.bat`：备用入口（最小化窗口运行，能直接看到报错，日常不用）
- 建议右键 `启动 lasso.vbs` → 「发送到」→「桌面快捷方式」，以后桌面双击即用
- 首次运行会自动下载 yt-dlp 引擎（约 17MB，页面会显示进度）
- 依赖：Node.js 18+（其他全部自动准备）

> 克隆仓库后请把 `ffmpeg.exe` 放入项目 `bin/` 文件夹（约 200MB 且为 GPL 许可，不随仓库分发）；
> 也可以不放置，lasso 会自动使用系统 PATH 里安装的 ffmpeg。没有 ffmpeg 时高清合并与 mp3
> 转换不可用，普通下载不受影响。

## 功能

| 功能 | 说明 |
|---|---|
| 📋 剪贴板感知 | 打开页面自动检测剪贴板中的链接并填好；输入框旁有粘贴按钮 |
| 🔗 批量下载 | 一次粘贴多个链接（空格/换行分隔），自动排队逐个下载；可一键切换「最高画质 / 仅音频 mp3」 |
| 🎚️ 清晰度选择 | 最高 8 档分辨率可选，带预估文件大小；也可只提取 mp3 音频 |
| 🎵 **抖音支持** | 详见下方「抖音是怎么下载的」；直链过期自动重新获取，无需手动重试 |
| 📂 一键定位 | 下载完成后「打开所在文件夹」直接高亮选中文件 |
| 📁 保存目录切换 | 页脚下拉可切换保存位置（下载/桌面/视频/图片/文档，限本机用户文件夹内），重启后记住 |
| 🕘 下载历史 | 最近 30 条记录保存在本地浏览器中，可一键重新下载或定位文件 |
| 🌐 网站列表 | 页面内可直接查看常用支持网站与完整列表入口 |
| 🔄 引擎自助更新 | 页脚「检查引擎更新」一键拉取最新 yt-dlp（某网站突然下载失败时先试这个） |
| 🩺 **环境自检** | 页面底部实时显示引擎 / ffmpeg / Edge / 保存目录状态，缺什么直接告诉你怎么装 |
| 🌗 深浅色 | 界面跟随系统自动切换 |

## 文件结构

| 文件 | 作用 |
|---|---|
| `启动 lasso.vbs` | **主入口**：双击无窗口启动服务并打开浏览器 |
| `停止 lasso.bat` | 双击停止后台服务 |
| `启动 lasso.bat` | 备用入口（最小化窗口，可看日志报错） |
| `server.mjs` | 本地服务器，纯 Node 内置模块，零第三方依赖 |
| `public/index.html` | 全中文网页界面 |
| `bin/`（不入仓库） | 可选：放 `ffmpeg.exe` 供内置调用 |

引擎默认下载到 `~/.lasso/bin`；如系统已装 yt-dlp 则直接使用。

## 安全与隐私

- 服务器只绑定 `127.0.0.1`，局域网其他设备无法访问
- **Host / Origin 双校验**：伪造 Host（DNS rebinding）或 Origin（浏览器跨站调用）的请求一律 403
- 只接受 `http(s)://` 链接；「打开文件夹」只接受当前保存目录内的路径，无穿越可能
- 保存目录只能切换到本机用户主目录内已存在的文件夹
- 下载历史仅存于本机浏览器 localStorage；进程退出时自动清理所有子进程与渲染用的 Edge

## 常见问题

**首次下载引擎失败？** 通常是网络无法访问 GitHub —— 开代理后重启程序会自动重试。

**YouTube 下载失败？** 下载国外网站需要系统代理；B站、抖音等国内网站不需要。

**某个网站突然不能下载了？** 平台改版会导致 yt-dlp 抽取器失效 —— 先点页脚「检查引擎更新」拉取最新版；抖音走的是 lasso 自己的通道，不受此影响。

**mp3 / 高清合并不可用？** 需要系统安装 [ffmpeg](https://ffmpeg.org)，安装后重启程序即可。

## 抖音是怎么下载的

yt-dlp 官方的抖音抽取器已因字节跳动服务端升级签名校验（Argus 系统）而**长期失效**
（无论是否带 Cookie 都返回 403），lasso 为抖音单独实现了一条下载通道：

1. **链接改写**：自动识别 `modal_id`、`/video/<id>`、`/note/<id>` 等链接形态，
   `v.douyin.com` 短链自动跟随跳转
2. **无头渲染**：调用系统自带的 Microsoft Edge（无界面模式）真实打开播放页，
   等页面把视频加载出来
3. **截获直链**：通过浏览器调试协议（CDP）监听网络请求，截获播放器实际使用的
   音视频 CDN 直链（有效期为数小时，即时使用无需保存）
4. **下载合并**：直接下载两路流，ffmpeg 无损合并为 mp4（或转 mp3）

解析抖音会比其他网站慢几秒（要真实渲染页面），属正常现象。需要登录才能观看的
视频目前无法下载。
